# Testing-Claudial-stuff

A playground. Things get built here for fun.

## Loose Ends

`loose-ends/index.html` is a tiny browser game about juggling plot threads before they turn into plot holes.

- Tap a pinned thread (or press 1–8) to write it. Only one at a time.
- Threads you aren't writing go cold. Three cold threads and your editor reads the draft.
- Shiny new ideas double your writing speed for a bit, and also pin a brand-new thread. Of course.

No build step, no dependencies. Open the file in a browser.
